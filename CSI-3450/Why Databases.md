Data can come from a variety of sources, and it must be stored. Examples of data sources are:
- Prescriptions
- Grocery
- Airlines
- Hotels
- Social media
All of these sources produce immense amounts of data, including customer information, business details, etc.
# Terminology
**Data**: Raw facts, such as customer name, address, phone number, or sales value.
**Information**: Processed data that is presented in a human-readable format. 
**Field**: A character or group of characters that has a specific meaning. 
**Record**: A logically connected set of one or more fields. 
## Data management
Adding, deleting, or modify data within a database.
## Database
A shared, integrated computer system used for storing data sets.
## Metadata
Data about data. 
## Database Management System (DBMS)
Software that oversees database structures and regulates access to the database. 

A DBMS allows data to be shared amongst multiple users, with certain users being able to access different parts of the database. 

Advantages:
- Improved data sharing
- Improved data security
- Better data integration
- Minimized data inconsistency
- Improved data access
- Improved decision making
- Increased end-user productivity
# Types of Databases
Multiuser databases supports fewer than 50 users or is used for a specific department in an organization.

Distributed databases are logically related databases are stored in two or more physically independent sites. 

Cloud databases are maintained by a third-party and not stored locally. 

General-purpose databases use a wide variety of data. 

Operational databases are used to support a company's everyday activities. Also referred to as Online Transaction Processing, Transactional, or Production. 

Analytical databases store business metrics. 
## Other definitions
Data Warehouses are specialized databases designed to store historical and aggregated data optimized for decision making. 

Online Analytical Processing is a set of tools that provide advanced data analysis for retrieving, processing, and modeling data from a data warehouse. 

Business Intelligence is a set of tools used to capture, collect, integrate, store, and analyze data to support business decision-making. 
### Unstructured data
Data that has not been processed. 
- Text documents
- Emails
- Social Media Posts
- Multimedia files
- Web pages
- Sensor data
### Structured data
Data that has been stored in a formatted table within a database. XML can be used to store structure data. Examples of structured data are: 
- Relational databases
- Spreadsheets
- Customer information
- Financial records
- Inventory data
- Employee records
