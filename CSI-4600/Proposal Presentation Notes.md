# Introduction
- Our project is called Transmission Link.
- It is designed to be a peer-to-peer voice chat application that takes advantage of similar technologies that discord uses.
- When we are complete with the project, it will either be able to have real-time or asynchronous voice messaging. 
# Objectives
- Our project is meant to be peer-to-peer. This means that two hosts will be able to directly communicate with each other without a third-party server involved.
- We will employ encryption standards to safely store user information.
- The UI will be simple and without clutter, enabling the user to get the most value possible out of the app. 
- Most of the technologies we plan to use will be open-source, which will expand the possibilities for us to develop Transmission Link. 
# Motivation
- The main motivation we have with creating this application is that privacy is slowly dwindling in many voice chat applications. We want to create something that enables quick, direct communication between two people with only an internet connection. 
- Some people may not feel comfortable sharing personal information via traditional VoIP apps. We want to be able to guarantee to users with this app that no third party is listening to their conversations. 
- Many user interfaces for voice chat apps are cluttered with a mix of text chat and voice chat. We want users to be able to directly initiate a voice chat with someone without having to dig through too many elements of the UI.
