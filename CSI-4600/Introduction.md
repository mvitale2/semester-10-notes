# Basic Definitions
Repeated from [[Network Definitions]]
- Data: Unsummarized, unanalyzed, detailed, facts.
- Information: Data that is processed by a computer program to be meaningful. 
- Knowledge: Using information to make decisions. 
- Computer Network: A set of interconnected computers. 
- Internet: A network of networks. 
- Application (program, protocol, software, command): A set of instructions.
- End system and host are equivalent. 
- Router: Hardware device that receives data/message from a switch and passes it to the next router or host.

# TCP vs UDP
TCP is meant to be as secure as possible while UDP prioritizes transmission speed. 
## Applications that use TCP
- HTTP
- FTP
- Telnet
- SMTP
## Applications that use UDP
- Streaming websites
- DNS
- Internet telephony
# Local Area Networks
LANs connect end systems to edge routers. 

Ethernet can have speeds between 10 Mbps and 10 Gbps.

LAN Transmission Categories:
- Unicast
	- A network communication method where data is sent from one sender to one receiver
- Multicast
	- A computer networking method that allows a single source to send data to multiple recipients simultaneously. 
- Broadcast
	- Streaming over the internet.
