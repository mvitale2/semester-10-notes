# Cost Estimation Tools & Techniques
- Analogous or top-down
	- Use the actual cost of a previous, similar project as the basis for estimating the cost of the current project. 
- Bottom-up
	- Involves estimating individual work items or activates and summing them to get a project total.
- Three-point
	- Estimating the most likely, optimistic, and pessimistic costs for items.
- Parametric
	- Uses project parameters in a mathematical model to estimate project costs.
